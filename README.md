# JAVA-DSA

Solved Java data-structures and algorithms problems.

```
src/    189 .java files across 21 topic folders
```

Every file is a standalone class with a `main` you can run. Where a problem
came from LeetCode, the class header carries the problem id and link, and the
javadoc carries the statement, examples and constraints as pasted from the
site. Comments below that are my own working notes.

## The revision site moved

This repository used to also hold a generator and a static revision site.
Those are now **[CodeAtlas](https://github.com/akashsundar9122000/CodeAtlas)**,
a separate project that reads `src/` from here and adds the full LeetCode
catalogue, an editor, code execution, spaced repetition and a dashboard.

This repo stays what it says on the tin: the solutions.

## Adding a solution

Write the class, run it, commit it. CodeAtlas picks it up on its next sync —
nothing here needs a build step.
